# Grade 4 Math Adventure

A simple Grade 4 mathematics game built with React, JavaScript, Vite, and Tailwind CSS.

## Features

- Addition, subtraction, multiplication, and division questions
- "Great Job!" popup for correct answers
- "Try Again!" popup for wrong answers
- Score and question counter
- Colorful three-color gradient background
- Simple popup and bouncing animations
- Responsive layout for desktop and mobile

## Run the project

Open Git Bash in this folder and run:

```bash
npm install
npm run dev
```

Then open the localhost address shown by Vite.

## Build for production

```bash
npm run build
```
